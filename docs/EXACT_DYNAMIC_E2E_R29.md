## Consumer boundary

The production runner accepts only `growth.dynamic_creator_external_review_envelope.r26.v1`. It checks the exact Growth producer and CI, exact Media R21 package authority, exact Bridge R30 capture authority, package/sealed-mapping digests, assistant-response/capture digests, round, source, candidate render/attachment bytes, selected-candidate identity and Growth handoff digest.

For `targeted_reedit`, R29 translates only the already-allowlisted Growth R26 directives into the frozen input shape required by the exact Media R21 checkout's R19 runtime. The translation is persisted as `creator.growth_r26_media_r19_adapter.r29.v1`. The old R19 Bridge R26/Media R18 fields are explicitly marked execution-schema compatibility only and are never accepted as live-review provenance. No model judgment is generated by Creator.

After the real Media effect, Creator verifies `media.editorial_reedit_application.v1`, render export and changed MP4 bytes, then builds the exact Media R21 `media.review_round_bundle.r21.v1` baseline-vs-reedit package. The package preserves the source Growth R26 handoff digest in `priorReview.decisionEvidenceDigest` and is the next external review boundary.

Replay is durable JSONL. Same round/review bytes are idempotent. A changed capture/assistant digest, package/sealed mapping, candidate hash or handoff conflicts before another side effect. Re-edit round 2 cannot start a third edit.

## One-command continuation

After a genuine coordinator-generated Growth R26 envelope exists:

```bash
creator-exact-dynamic-r29 continue \
  --media-checkout /path/to/video2-at-d753e9e4 \
  --growth-checkout /path/to/video3-at-e844ed2d \
  --bridge-checkout /path/to/WebAIBridge-at-ceaee873 \
  --candidate-root /path/to/materialized-candidate-root \
  --candidate-context /path/to/candidate-context.json \
  --growth-envelope /path/to/growth.dynamic_creator_external_review_envelope.r26.v1.json \
  --out /path/to/r29-output
```

Windows PowerShell uses the same arguments with Windows paths.

Readiness without a genuine envelope:

```bash
creator-exact-dynamic-r29 readiness --out r29-readiness.json
```

The readiness command exits 2 by design while the genuine capture is absent.
